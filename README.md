# Java OOP Assignments

My assignment solutions for the STEP Sem-3 Java / OOP course.

## Structure

Each week's problems go in their own folder:

- `week5-arrays-methods/` — Category C problems on arrays, methods, constructors,
  `static`, and `Comparable` (fantasy-sports themed)

## Running the code

```bash
cd week5-arrays-methods
javac *.java
java FantasyTeamScoreMultiplier
```

Every file has a `main` method that runs the example cases from the assignment PDF.
